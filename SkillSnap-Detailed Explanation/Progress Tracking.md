# 📊 Progress Tracking — SkillSnap

## 📌 Overview

**Progress Tracking** helps users understand how much they have learned, what they have completed, and which skills still need improvement.

Since SkillSnap supports multiple learning areas, users should be able to monitor their progress across **academics, hobbies, creative skills, sports, and other interests** from one place.

---

## 🎯 Why Progress Tracking?

When users learn multiple skills, it can be difficult to remember:

* What they have completed
* What they are currently learning
* How much they have improved
* Which skills need more practice
* What they should learn next

SkillSnap brings this information together in a simple progress view.

---

## 🔄 How It Works

```text id="q5r8cx"
Start Learning
      ↓
Complete Lessons / Activities
      ↓
Practice the Skill
      ↓
Update Progress
      ↓
View Improvement
      ↓
Continue Learning
```

## 📚 Track Different Learning Areas

Progress can be maintained separately for different skills.

For example:

```text id="b7v2pd"

├── Java          75%

Creative Skills
├── Drawing       55%

Personal Skills
├── Guitar        65%
```

This gives users a clear picture of their overall development.
