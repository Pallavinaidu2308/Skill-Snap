# 👤 Personalized Dashboard — SkillSnap

## 📌 Overview

The **Personalized Dashboard** acts as the user's central space in SkillSnap.

Instead of searching through different sections every time, users can see their **learning activities, selected skills, progress, goals, and achievements** from one place.

The dashboard is personalized according to what each user chooses to learn.

---

## 🎯 Purpose

The main purpose of the dashboard is to give users a quick overview of their entire learning journey.

```text id="y5n7dk"
                 My SkillSnap
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
   My Skills       Progress       Goals
        │             │             │
        └─────────────┼─────────────┘
                      ▼
                 Achievements
```
