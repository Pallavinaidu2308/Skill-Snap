# ⭐ Core Features — SkillSnap

## 📌 Overview

SkillSnap is designed to bring different forms of learning together in one platform.

Instead of focusing only on academic education, the platform allows users to explore **academic subjects, creative skills, hobbies, sports, music, cooking, personal development, and many other areas**.

The following features form the foundation of the SkillSnap experience.

---

# 📚 1. Multiple Learning Categories

SkillSnap supports different types of learning instead of limiting users to one category.

### Categories can include:

```text id="y7k2mz"

💻 Technology
🎨 Art & Creativity
🎵 Music
💃 Dance
⚽ Sports
🍳 Cooking
📷 Photography
🌱 Gardening
💡 Life Skills
🗣️ Communication
🚀 Personal Development
```

Users can explore whichever categories match their interests.

# 👤 2. Personalized User Profile

Each user can create a profile based on their interests and learning goals.

The profile can contain:

* Selected skills
* Interests
* Learning goals
* Skill levels
* Completed courses
* Progress
* Achievements

Example:

```text id="k9p3vx"

✓ Java
✓ Drawing
✓ Guitar
✓ Cricket

My Goals

🎯 Improve Programming
🎯 Learn Guitar
```
